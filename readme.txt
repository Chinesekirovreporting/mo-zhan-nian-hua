WOW 插件内通讯技术 

同步范围：
	WHISPER	指定 1 人（点对点）	1	否（可定向用）
	PARTY	小队	5	✅
	RAID	团队	40	✅
	INSTANCE_CHAT	当前副本内成员	副本内	可替代 RAID
	GUILD	公会全体（跨地图/跨副本）	公会人数	✅
	OFFICER	公会官员	官员数	否
	RAID_WARNING	团队+小队（醒目警告）	40	否
	BATTLEGROUND	战场同阵营	战场内	否
同步方案： 
	1.房主权威 + 全量快照（房主为主+同步全体） -- 房主绝对权威 + 定向同步其他客户端（状态同步） 
	2.服务器权威1（拉去魔兽服务器数据） 		-- 所有的数据由远端拉取 （外部定向内容）
	3.锁步/帧同步 							-- RTS，局域网跳棋，一人卡全团等，同初始状态 + 相同规则各自本地重放 （帧同步） 
	4.对等式 + 冲突合并(CRDT) 无中心 			-- 各自记录自己账本的内容 + 合并账本 （去中心）
同步时机：  
	本地渲染帧回调：
		客户端帧函数约 60 次/秒
	事件驱动： 
		代码事件驱动同步 
		用户点去驱动同步 
		游戏内系统事件驱动同步（收到消息）
	时间驱动： 
		周期心跳 
	主动请求同步： 
		自检验证不一致进行同步 
同步约束：
	序列化与压缩 
	分片与重组（切片发送）
	快照与增量 
	事务确认 
	限速保护
